This repository is a teaching project (**Classwork**) dedicated to mastering the fundamental aspects of **Asynchronous Programming** in Vanilla JavaScript.

### 💡 Key Concepts

* **Timers**: Utilizing `setTimeout`/`setInterval` to control the execution timing of functions.
* **Event Loop**: Understanding the task queue mechanism that allows JavaScript to process asynchronous operations without blocking the main thread.
* **Promises**: The modern approach to managing asynchronous code, which resolves the Callback Hell problem and ensures clean handling of success and errors.
* **Promisification**: Converting older callback-based asynchronous code into a new, Promise-oriented structure.

### ▶️ Getting Started

Simply open **`index.html`** in your browser and check the script outputs in the **Developer Console (F12)**.
